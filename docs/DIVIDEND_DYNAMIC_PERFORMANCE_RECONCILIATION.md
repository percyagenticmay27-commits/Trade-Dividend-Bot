# Dividend-001 performance reconciliation: dynamic exits and pooled SGOV

**As of November 19, 2026.** The read-only performance refresh now combines two **non-overlapping accounting eras**: historic paper round trips from `paper_trade_log.csv` (June–August) and dynamic pair/leg round trips from `state/dividend_dynamic_sleeve_transactions.jsonl` (September onward). A dynamic sale is matched to the most recent valid preceding buy **by sleeve ID and INCOME/GROWTH leg**, never by the SGOV symbol or by the pair alone. Each exit has an immutable `exit_transaction_id`, and duplicate buy openings without an intervening exit are flagged and excluded from completed-trade counts. Dynamic authoritative zero-share holdings supersede stale legacy unmatched opens.

Each dynamic row preserves buy transaction ID, exit transaction ID, entry principal, gross exit proceeds, `pnl=proceeds-entry_principal`, separate paid/reinvested or parked distribution evidence and `sgov_receipt_status`. Reinvested distributions are reflected in the shares sold and must **not** be added to that P/L again. Separately parked dividends are not treated as exit proceeds. **Gross proceeds are not trading profit**. The report's realized P/L reflects completed trading round trips, whereas current SGOV principal is a separate balance-sheet amount.

`state/dividend_sgov_ownership.json#funded_exit_receipts` is an authoritative **subset** of historical sales: each available receipt is joined by sale transaction ID and validated against sleeve ID and two-decimal proceeds. Legacy dynamic sales without individual receipt evidence are included as journal-evidenced realized trades but flagged `HISTORICAL_NO_FUNDED_EXIT_RECEIPT`; they are *not* credited to SGOV again. Reconciliation also requires `SGOV principal = unassigned reserve + member attributed cash`. Nonspendable SGOV valuation adjustments remain separate from principal. A receipt amount mismatch, dangling receipt, malformed transaction ID, unsafe paper flag or current reserve accounting mismatch raises an error rather than overwriting the report with fabricated totals.

On initial repair, source reconciliation reports **6 historic legacy closes + 20 dynamic leg closes = 26**, with combined historical realized P/L **-$464.39** (legacy **-$155.01**, dynamic **-$309.38**). There are **8 funded exit receipts totaling $4,050.76** all matched exactly, with **12 earlier sales lacking a separate receipt**. A historical duplicated `PLTW/PLTU` buy transaction (both legs) is disclosed as two unmatched older openings rather than double-counted. SGOV principal **$4,222.66** reconciles to **$2,139.72 attributed + $2,082.94 unassigned**; valuation adjustment **$2.73** is not spendable. These amounts are snapshots, not fixed settings, and future refreshes must recompute them from source.

The normal scheduled `refresh_dividend_paper_trade_performance.py` and `dividend_daily_evidence_refresh.py` already call this report writer. No entry, exit, broker execution, stock purchase, SGOV transfer, allocation or other paper state is mutated.
